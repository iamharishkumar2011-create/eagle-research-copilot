# 🦅 Eagle — Research Copilot

A 6-agent research workflow tool for faculty, built with Streamlit + Claude.

## Stages
1. **Problematize** — Socratic questioning to sharpen a fuzzy idea into a research question
2. **Theorize** — Build theoretical lens and construct map
3. **Literature** — Real papers from OpenAlex + synthesis
4. **Method** — Survey instrument (quantitative) or interview protocol (qualitative)
5. **Reviewer** — Devil's advocate critique at journal level
6. **Full Paper** — Auto-fix critique + generate Introduction, LR, Hypotheses, Method, and 4+4 Implications

## Setup
```bash
pip install -r requirements.txt
streamlit run sherpa_app.py
```

## API Key
Enter your Anthropic API key in the sidebar when prompted.
